# セキュリティ上の問題の報告

v0.1.0を対象にセキュリティ修正を受け付けます。

脆弱性は、GitHubの[非公開報告](https://github.com/NBE03xxx/keepassxc-gnome/security/advisories/new)から報告してください。公開Issueには脆弱性の詳細や秘密情報を記載しないでください。

報告にはアプリの版、Ubuntuの版、再現手順を含めてください。実際のパスワード、キーファイル、本番データベースは送らず、合成データで再現してください。

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/NBE03xxx/keepassxc-gnome/security/advisories/new), not public issues. Include the application and Ubuntu versions and reproduction steps using synthetic data. Do not send passwords, key files, or production databases.
