# Phase 3 — アプリ実装と製品化前検証

2026-11-12 の利用者の指示により、調査から実装へ進む。

## 完成条件

- GTK4 / libadwaita で DB の作成・解除・ロック・保存、グループとエントリーの作成・編集・削除、検索、パスワード生成、コピーができる。
- UI は環境に応じて日本語・英語を選び、それ以外は英語にする。明暗はシステム設定に追従する。
- 暗号と KDBX は KeePassXC の既存処理を使い、既存データと未表示の属性、履歴、TOTP 設定、添付を保持する。
- 互換性の基準は、本家が通常保存する既知データの往復保持とする。保持できない入力は理由を示して拒否する。
- 読み込みの検証が完了するまでモデルを公開せず、保存失敗・外部更新・画面ロック・スリープ時の動作を確認する。
- 固定した上流、独立したソース、再現可能なビルドとテストをプロジェクト内に保持する。
- deb の導入・更新・削除は Ubuntu 26.04 の VM で先に検証し、その後に利用者と実機で最終確認する。

## 進め方

まず初期試作を再ビルドできる基盤と必須機能の実装を整える。調査報告書 §13〜§22 のデータ保持・読み込み上限・KDF・終端検証を製品化の合格条件として扱う。上限値や未対応機能で保存できない場合は、利用者に理由を示す。

開発中は合成データを使う。依存パッケージの追加、上流修正、公開と実インストールには AGENTS.md の規則を適用する。結果は phase3-results.md に、実装済み・検証済み・未完了を分けて記録する。

## 2026-11-13 の優先順位の確定

1. 本家 KeePassXC が通常保存する既知データの互換性・保持を検証する。
2. 保持できない入力を理由付きで拒否する。
3. 任意の未知構造の再保存は検討結果を記録するのみとし、実装しない。完成条件・今後の実装予定から外す。

判断と範囲は [互換性方針](compatibility-policy.md) に記録する。3 の実装は、新たな利用者の指示なしに開始しない。

## 2026-11-14のUI改修の指定

本家KeePassXCに倣い、左はグループ、右上は選択グループのエントリー一覧、右下は選択エントリーのプレビューとする。名前の前のアイコンと利用者のアイコン選択、初期状態で閉じたグループと開閉矢印、単一選択のプレビュー、ダブルクリック・Enter・編集ボタンでの編集を整える。プレビューの左端側に編集・削除・コピー操作を置く。保存互換性とロック時の秘密消去を維持する。

グループは左の鉛筆ボタン「グループを編集」から名前とアイコンを同じ画面で変更できるようにする。アイコンの本家との表示・保存互換性を説明し、グループ編集は一組の変更として復旧へ保護する（2026-11-14の追加指示）。

既存DBの解除ダイアログはパスワード欄のEnterでもボタンと同じ解除処理を行う。起動直後の未選択状態は「データベースが開かれていません」とし、実際に開いたDBをロックした状態と区別する（2026-11-14の追加修正依頼）。

2026-11-14の追加UI指示：初回は歓迎メッセージ・鍵アイコンと中央の新規作成／開くボタンを置く。説明は「新しくデータベースを作成するか、お持ちのファイルを開いて始めましょう。」。直近に正常に開いた／関連保存した1件だけを履歴とし、削除できるようにする。固定の既定DBを指定する機能とはしない。次回は解除を案内するがDBを自動読込せず、毎回パスワードを要求する。開いているファイルのbasenameを控えめに表示する。公開向けの通常文言から検証用の表現を除く。KDBXの関連付けは本家と本アプリを選べるようにし、明示済みの既定関連付けをインストールで上書きしない。詳細は `docs/welcome-recent-file-associations.md`。

2026-11-14の追加指示：編集後の未保存状態を色だけでなく印・文言でも明示する。終了確認に保存（通常は関連先へ上書き、新規等は保存先を選択）を加え、保存失敗や取消でアプリを閉じない。主要ボタンとエントリーの選択にGNOMEのアクセントカラーを使い、環境の変更へ追従する。詳細は `docs/unsaved-close-accent.md`。

2026-11-14の追加指示：小さな入力画面の主操作をEnterでも実行できるようにする。エントリーの単一行入力からは保存と同じ確定操作へ進み、複数行メモの改行やフォーカスされた補助ボタンの動作は保つ。無効入力は実行しない。選択行のアクセントは固定20%の混色で薄くし、文字・アイコン自体は薄くしない。詳細は `docs/default-actions-selection-tint.md`。
