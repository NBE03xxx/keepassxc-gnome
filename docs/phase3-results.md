## XML・モデル件数と保持可否

2026-11-13 に [XML・保持の記録](xml-model-preservation.md) を追加した。XML 深さ128、開始要素100万、生成・追加合計25万と、Group / Entry・履歴・添付・属性等の個別予算を適用する。一時オブジェクトと参照先の生成も検査し、上限で停止した後の null や履歴の後始末を扱う（`prototype/ReadLimits.h:27`、`src/gnome/ReadBudget.h:71`）。

未知の XML 要素・属性・ヘッダー・フラグ、保持できない辞書や未解決参照などは、モデルの公開前に `UnsupportedData` として拒否する。任意キーのカスタム属性・CustomData、TOTP・履歴・添付・Auto-Type データ等は、既存モデルが保持できるものを再保存して照合する。**未知構造そのものを読み込んで再保存する機能は、検討記録のみとする決定により実装対象から外した**。

新しい323ケース、既存352ケースと196ケース、無変更の上流 CLI との互換性、上流テストと言語試験の合計 CTest 12項目が成功した。独立 GNOME Wayland 環境の日本語 UI 操作も成功した。別ビルドの AddressSanitizer と LeakSanitizer でも323ケースに指摘はなかった。これは検査した経路の結果であり、全ての入力に対する安全性や秘密の全消去を証明するものではない。

既知の拡張点の保持と、未対応構造の拒否を分けて扱う。今後はプロセス単位の制限と中断、保存と復旧、本家データに対する保持可否検査の拡大を評価する。実データ利用・公開の合格条件は引き続き未達。

## 互換性の優先順位の確定

2026-11-13 の指示により、本家の通常保存データの互換性・保持を最優先し、保持不能な入力の理由付き拒否を維持する。任意の未知構造を再保存する機能は、[検討結果](compatibility-policy.md)を保存するのみとし、実装対象・完成条件から外した。この決定は AGENTS.md と Phase 3 指示書にも反映した。
