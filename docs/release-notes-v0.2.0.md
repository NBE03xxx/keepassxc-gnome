# KeePassXC GNOME v0.2.0

既存のKDBXを、本家KeePassXCで作成したキーファイルで解除できるようになりました。キーファイル単独とマスターパスワードとの併用に対応します。保存や復旧にも、解除時と同じ鍵の組み合わせを使います。

- キーファイルだけで解除するには、「マスターパスワードを使用する」をオフにしてキーファイルを選びます。
- パスワードと併用するには、チェックをオンのまま、既存のパスワードを入力して同じキーファイルを選びます。
- キーファイルは毎回選択します。生成やDBの鍵設定の変更には本家KeePassXCを使います。

Ubuntu 26.04（amd64）用のdeb、完全対応ソース、ビルドmanifest、SHA256SUMSを添付しています。配布物は未署名です。debのSHA256を照合し、アプリを終了してから次のコマンドでインストールまたは更新してください。

```bash
sudo apt install ./keepassxc-gnome_0.2.0-1_amd64.deb
```

長時間の利用や反復操作でメモリ使用量が増える既知の問題があります。対応範囲は[利用ガイド](https://github.com/NBE03xxx/keepassxc-gnome/blob/v0.2.0/docs/user-guide.md)を参照してください。
