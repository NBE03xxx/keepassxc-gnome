# 残件の最終判定と公開候補の準備

2026-11-14。対象はUbuntu 26.04 / GNOME 50 / Wayland、短時間の個人利用。開始時点の修正・VM・実機記録を `a8e44b219156a54836661f6e3d620b26ebdb6af4` としてGiteaへpushした後の作業。本書の追加検査・文書はそのpushに含まれない。

## 判定

dev5での保存・保持・資源制限・ロックと、VM→実機の検証は従来の記録を維持する。追加のOrca条件比較は日本語・英語各28チェックが成功し、通常欄と明示表示で発話、伏せ字で英字非発話を確認した。今回の比較により修正すべき製品コード不具合は再現していない。初回の入力条件不明という観測は解決扱いにしない。

正式な公開・実データ運用の最終受入は未実施で、現在の開発版表示を維持する。公開用連絡先等の確定を待つ間に候補を作る場合は、**非公開のリリース候補**として扱う。既知の制限・未検証を削除して安定版に見せる処理はしない。

[非公開RC1](release-candidate-rc1.md)の共通検査・対応ソース再ビルド・梱包再現とUbuntu 26.04 VMの導入・更新・削除・GUI・寿命103チェックを完了した。実行用payloadは実機確認済みdev5と同一で、実機の追加更新は行っていない。利用者自身の[起動・操作確認](manual-acceptance.md)後、改めて公開の明示指示があるまでGitHub公開を保留する。

その後、利用者指定の[UI改修](navigation-preview-ui.md)を行い、[dev6のVM検証・実機更新と日本語ロック画面での起動](navigation-preview-candidate-validation.md)を確認した。RC1・dev5は改修前の記録として維持し、新UIの一通りの実機操作は利用者自身の確認を待つ。標準69種類のアイコンを選択できるが、既存カスタム画像は保持のみで汎用表示という制限を追加記録した。新UIのOrcaは日英各31チェックが成功。公開は引き続き保留する。

## リリース検査入口

`tools/check-release.sh` は `KPXC_RELEASE_VERSION` と `KPXC_RELEASE_OUTPUT` で対象を固定できる。保存先が非空なら検査前に拒否し、既存のdeb・対応ソースを上書きしない。指定しなければ新しい `build/release-check.XXXXXX/` を作る。既定の版は従来互換の開発版なので、候補では版を明示する。

入口は日英のOrca比較、実サイズを含むguard警告、自動検査、梱包、完全ソースの再ビルド、同じ版での再現梱包を行う。実際のOrcaを使うrunnerが必要で、パッケージを自動インストールしない。GUI全体の生LSanの既知結果や長時間試験を、この入口の成功で上書きしない。
